## Gap between the author's absolute numbers and ours

- verdict: **workload mismatch (micro-bench regime) + unit label bug** — Author: 27 % on `rearrange` (1.37 s → 1.08 s) inside a live `-dp 8` Qwen3-Next-80B EPLB rebalance (58 MoE layers × 512 physical experts, real P2P), plus "20-25 % per primitive" unquantified. Ours: three inlined primitives at `NUM_LOCAL=16`: `get_ep_ranks_with_expert` 8.2× faster (consistent with the author), but `move_to_buffer` 0.74× and `move_from_buffer` 0.38× — at 16 local experts the pure-Python body is 16×16 = 256 trivial iterations (23 µs) while the numpy body pays ~10 numpy-call overheads (31 µs); numpy only wins once `num_local_experts` and the per-layer loop are large. The headline/median therefore reports a regression the author never claimed. Also: `bench.py:_best_ms` returns **ms** (`*1e3`) but `task.json` declares `unit: "us"` — every 29499 number on the dashboard is mislabelled by 1000×. To match the author: bench the whole per-layer rebalance (loop over all `ep_rank`s × 58 layers, i.e. the `rearrange_expert_weights_inplace` index-mapping path with `num_local_experts` ≥ 32 as in Qwen3-Next with 32 redundant experts), make `get_ep_ranks_with_expert` or the E2E loop the headline, and fix the unit to `ms`. Verdict: workload, not hardware (CPU-only).

## Measurement policy (as pipeline/run_one.sh implements it)

- repeats: 5 per arm; ABBA across arms per repeat (A,B,B,A,A,B,...); one run = one `docker run` of the workload cmd per arm per repeat (same image, arm tree swapped in by the prelude)
- GPU pin `--gpus device=0`, env ['CUDA_DEVICE_ORDER=PCI_BUS_ID', 'CUDA_VISIBLE_DEVICES=0', 'HF_HUB_DISABLE_PROGRESS_BARS=1'], `--shm-size=2g`, per-run cap `WL_TIMEOUT=20m`
- GPU warm-up 2.0 s in the prelude; contention gate: wait while another tenant uses the GPU (>5 % util or a foreign compute process >1 GiB) or the CPU (load1 > nproc/2) (max wait 600 s, then run anyway, flagged in data/pr_<n>/work/contended_<arm>_<i>.txt)
- arm isolation `tree`: wipe the wheel's vllm/*.py, copy the arm's vllm/ over site-packages (compiled .so stay); machine.py snapshot per workload run -> data/pr_<n>/work/machine_<arm>_<i>.json
- noise model: measure.py: paired log-speedup, MAD sigma, theta = clip(k*sigma, theta_min, theta_max) with k/theta from config.yaml:measure
